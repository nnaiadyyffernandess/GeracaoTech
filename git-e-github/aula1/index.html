O crtl " acessa o terminal. Sempre escolha abrir pelo bash ao invés do powershell, pois é mais explicativo.

O comando no terminal git status mostra os commits, o estado do arquivo.

git add index.html : adiciona uma modificação, atualização prontas para serem comitadas. Você adicionou a alteração dentro da bolsinha, por assim dizer. Esse comando pede que usemos o nome do arquivo

git reset: tira qualquer atualização

Quando houver vários arquivos, para não repetir várias vezes o git add, podemos fazer git add . , ele adiciona todos os arquivos da pasta.
